**第19节   压力和焦虑**

一、压力和焦虑的来源

* 未完成的事件  
* 不确定性  
* 被动性  别人交给你，或者不得不做的事
* 缺乏性 缺钱

1.未完成事件

1.1  清理房间一样，全列出来，放客厅里

* 第一类：几分钟可以做完的
* 第二类：不是几分钟可以完成，分解出第一步开始做
* 第三类：最近的无需行动的，放到日程上

1.2  对于一天的工作，要做这样的计划：

* 第一  只有重要的事：全列出来，按重要程度，慢慢删
* 第二  学会估算时间，并且预留时间
* 第三  设定执行的环境和地点
* 第四  预估可能遇到的障碍和问题
* 第五  拆解任务
* 第六  做完之后回顾要事的完成情况，再做其他计划

2.不确定性：得到差评、失败、被拒绝等

**第21节  语言价值理论**

```
**说话其实是一场交易，所以一定要给到对方价值**
**时间耐心成本<价值=无聊厌恶**
**时间耐心成本>价值=愉悦欢迎**
```

一、启示

* 1.第三人觉得好，不是好，要注意对方的感受
* 2.听的风险比较小，听的时候给出反馈更好，缺点，展现不出价值
* 3.多说一些价值高的话，赞美，表扬，鼓励

二、满足对方价值

1.原则

* 1.了解对方需求                  情商的体现
* 2.了解人类的共同需求       爱，安全感

2.换位思考

* 1.观察、记录自己厌恶和不舒服的时刻：    记下来，约1年，已开始
* 2.提问和反馈：   有些可以问出来
* 3.收集第三人的证据：    他人的不适

情商高的人是掌握了基本人性和一些说话技巧

3.无价值谈话

* 1.无用的、无聊的    
* 2.直接引起对方消极感受的   批评、斥责
* 3.提示未来风险   说别人坏话，炫耀别人暂时未拥有的

4.风险高的话，怎么说

先肯定情绪，再听，最后说方案！

1.批评：

1. 先让对方说；
2. 找出可替代、错误环节，给出建议；
3. 表达期待；

2.反对：

* 合理化对方的感受，出了事，这个反应很正常，可以理解；
* 从自己的经历和角度出发，我觉得你的方案不太合适，我自己也不一定是对的

3.说服：

* 先让一步，再进一步，先对方否定你一次；
* 道理、利益、情感的顺序，最易接受

4.请求：不能用祈使句

1. 如果你要这么做的话，好的结果是什么
2. 只有你才可以这样，非你不可
3. 感谢，无价值的话+有价值的话

5.安慰：对方情绪不稳定的状态

1. 不要分享自己的经历和感受；对方失去了注意力、关注，被冷落了
2. 不要上来就提建议；对方觉得自己弱，自己不行
3. 肯定和支持对方的感受；不要说“没关系”“不应该”；此刻的一切反应都是对的
4. 行动上关心

6.拒绝：对方姿态降低，拒绝之后更低，所以要照顾对方情绪

1. 理解对方的困境
2. 找出拒绝之后对他好的方面
3. 强调自己的不便
4. 什么情况下一定会提供帮助

三、价值高的话，怎么说

1. 表扬：具体到事情；认可对方的个性；     最重要的是可信度高
2. 感谢：感谢+表扬；感谢+承诺
3. 答应：不要吹嘘自己的能力；可以表达对对方的肯定

* 一切的前提：能给别人提供帮助；拥有独立、深刻的看法

**第25节  人际关系分层理论**

一、社交价值理论说明

1. 不要觉得只有强大了才可以去社交
2. 不能封闭自己，不出去社交
3. 一个人的社交价值，取决于他本身的价值和开放程度(他会不会帮你)

二、社交价值理

1.社交的四个价值

* 信息价值：八卦，新信息，新知识，互联网发展，逐渐减弱
* 资源价值：(工作人脉和客户关系)
* 情绪价值：(家人和伴侣)领导，服务业
* 智力价值：特别聪明的人

情绪价值包括

1. 情绪承载力：遇事不崩，从容面对
2. 情绪洞察力：感知他人情绪状态
3. 情绪感染力：同理心，共情能力

2.社交成本  投入的时间、精力、金钱

3.社交风险   人品风险

**要把社交价值、成本和风险结合在一起看问题**

三、人际关系分层理论

1. 亲密层：家人、要好的朋友(主要目的：爱)
2. 人脉层：提供帮助；常规联系；(提出合理要求，对方不做，下调至社交层)
3. 社交层：点头之交，礼貌，互相尊重；一般不会帮你；也不需要常联系

亲密层>人脉层>社交层

四、实践中需要注意的点

1. 社交价值的误判：社交层的人误划为亲密层，冷
2. 社交时间分配失衡(学会拒绝)：别人把人划为亲密层，拒绝
3. 接纳自我的陷阱：不变化，静止；一定要有价值，被别人需要
4. 社会价值不够的时候，展示开放的状态：聚会，自我介绍；我是谁，我可以为你做什么，需要时来找我
5. 主动求助，不要害怕拒绝：人脉层主动时，会更紧密

五、最高效的社交方法

* 提升自我价值=提供更多帮助
* 寻找到社交明星去搭建人脉网=减少时间和精力
* 注意社交礼仪=打一枪，跑一群鸟

**第26节  主动管理印象，而不是留下印象**

* 不要多
* 不要冲突

一、管理印象
1.利用外表：衣服会反映人的印象

1. 找对人，模仿他的穿着
2. 在朋友圈频繁曝光(多看效应)，发有故事的照片

晕轮效应：在人际交往中，人身上表现出的某一方面的特征，掩盖了其他特征，从而造成人们认识的障碍。

2.利用语言

1. 自我声明：声称自己是个什么样子的人
2. 观点和态度：对于公共事件(11岁小女孩)，生活事件(朋友和媳妇吵架)，
3. 一定要问自己：如果一个人这么说，我会怎么想？

3.利用正面连接

* 连接一些品牌和书籍：用“我喜欢的”来标榜我
* 连接好消息，而不是负面消息

4.利用积极期待

* 如果我们用消极期待面对对方，我们得到的也是消极的对待

5.管理别人的期待

* 降低别人的期待
* 利用近因效应(最近做的事)去管理印象

6.抓住时机，超出期待

* 利用一两个时机，突出表现来固化他人对你的好印象
