# 左上肺叶切除 - 单孔单向式流程优化

  

> 左上肺单向式的瓶颈结构与右上肺本质不同：**不在第一步的静脉，而在深部的 A1+2+3**。左侧肺动脉干走行短、分支早，A1+2+3 位置最深，且舌段支气管/动脉在解剖上交叉——处理顺序的选择直接决定手术时间与安全边界。

  

---

  

## 一、解剖难点分析

  

```

        主动脉弓

       ╱        ╲

  第5/6组LN      第7组LN

       │

  ┌────▼─────────────┐

  │  A1+2+3 ←核心瓶颈 │ ← 位置深、走行短、分支早

  │   ↕ 交叉          │

  │  上叶支气管        │ ← 舌段支气管(B4+5)与A4+5交叉

  │   ↕               │

  │  A4+5（舌段动脉）  │ ← 本流程在 A1+2+3 后处理，注意分支变异

  │   ↕               │

  │  左上肺静脉        │ ← 第一步，痛点在V4+5共干辨认

  └──────────────────┘

```

  

- **A1+2+3 难点**：左侧肺动脉干较短、分支较早，A1+2+3 可游离段有限，深部暴露是全流程的核心卡点。

- **静脉难点**：V4+5 可存在汇入方式变异，术前应结合增强 CT/三维重建确认其与下肺静脉及左房的关系，术中不以固定分支模式替代实际解剖。

- **淋巴结挑战**：第 5/6/7/10L/11L 组，其中 5/6 组位置特殊，需嵌入主流程清扫。

  

---

  

## 二、路径选择：本笔记标准路径 vs 困难时个体化调整

  

| 路径 | 顺序 | 适用场景 |

|------|------|---------|

| **本笔记采用的标准单向式** | V → A1+2+3 → A4+5 → B → 叶裂 | 从肺门前方按既定方向逐层推进；各结构均需确认后分别处理 |

| **困难时个体化调整** | V 后根据实际暴露调整 A1+2+3、A4+5 与 B 的顺序 | A1+2+3 暴露困难、钙化淋巴结粘连或血管变异；不机械套用固定顺序 |

| 肺裂优先逆向 | 叶间裂 → A1+2+3 → A4+5 → V → B | 叶间裂发育好、A1+2+3 浅（少用） |

  

> **决策点**：A1+2+3 暴露不清时，不在深部肺动脉上反复盲目分离。完成近端肺动脉控制、明确上下叶支气管解剖并确认下叶通气后，可根据术者经验调整为先处理 B；若仍不能建立安全平面，应及时中转开胸，而非以缩短时间为目的强行推进。

## 三、分步优化要点

  

| 步骤 | 优化要点 |

|------|---------|

| **V（左上肺静脉）** | ① 术前增强 CT/三维重建确认上肺静脉及 V4+5 汇入方式；② 术中明确上、下肺静脉边界及静脉后方结构后建立安全通道；③ 整束或分支处理应依据实际静脉解剖与安全击发角度决定，不预设为 V1+2、V3 两支分别离断 |

| **A1+2+3（核心瓶颈）** | ① 建立动脉窗（A1+2+3 与上叶支气管之间）≥1.5cm 再过吻合器；② 分支优先：A3 先断（浅）、A1+2 后断（深）；③ 分离后缘前在肺动脉主干预置血管阻断带 |

| **A4+5（舌段动脉）** | 本流程在 A1+2+3 之后处理；从叶间动脉发出处追源，确认 A4、A5 数目、共同干及纵隔型舌段动脉等变异后分别处理，避免将下叶动脉误认为舌段动脉 |

| **B（上叶支气管）** | ① 第 5/6/10L/11L 组淋巴结随前序步骤前移清扫（5 组经静脉后间隙、6 组沿主动脉弓前缘），到支气管步骤时已"骨骼化"；② 咬合点在上叶开口处，残端 2–3mm；③ 击发前鼓肺（20 cmH₂O）确认下叶通气；④ 注意保护左主支气管膜部，防支气管动脉瘘 |

| **叶裂** | 叶裂通常作为本流程最后一步完成；叶裂发育不全时可采用 fissure-last 思路，以切割闭合器从已建立的安全平面逐步完成，不能表述为“无需处理” |

## 四、A1+2+3 与支气管钙化/碳化粘连：应急流程

  

**触发条件**：V 已处理，A1+2+3 与上叶支气管因钙化/碳化淋巴结紧密粘连，**无法建立后方安全通道**。A4+5 是否已处理取决于实际暴露，不能作为固定前提。

  

**止损阈值**：A1+2+3 后方分离 3–5 分钟未通、视野血污加重 → 立即启动本流程，不在钙化区硬剥。

  

```

Step 1  安全前置（不可省略）

        ├─ 近端肺动脉控制带（提拉即可部分阻断）

        ├─ 确认左下叶支气管走行 + 鼓肺确认下叶通气

        └─ 中转开胸准备（告知麻醉/护士备开胸器械）

              │

Step 2  可控开放/部分离断左上叶支气管

        ├─ 保守档：前壁部分切口（环周1/3–1/2），保留后壁

        ├─ 激进档：完全横断，远端随肺叶牵向头侧

        └─ 从保守到激进分档推进；紧贴上叶开口远端，留残端≥5mm

              │

Step 3  从远端或侧方安全处理 A1+2+3

        ├─ 远端入路：从已断支气管远侧逆向分离，沿动脉外膜向近端推进

        ├─ 侧方入路：从非钙化侧绕过钙化块

        ├─ 禁止将未明确边界的钙化块与肺动脉整块盲目击发；无法安全游离时及时中转开胸

        └─ 分支优先：A3 先断、A1+2 后断；贴钙化块侧锐性分离，远离动脉壁

              │

Step 4  规范闭合左上叶支气管残端

        ├─ 修整残端确保平整

        ├─ 直线切割闭合器规范闭合（支气管壁厚/钙化用绿仓）

        ├─ 击发前鼓肺确认下叶支气管未被夹闭

        └─ 成钉不满意 → 3-0可吸收线间断缝合 + 生物胶加固

        ※ 若 A4+5 尚未处理，应在确认其起源、走行及下叶动脉分支后单独离断

              │

Step 5  验证 + 应急

        ├─ 鼓肺 20–30 cmH₂O：下叶膨胀良好、残端无漏气

        ├─ A1+2+3 残端无活动性出血；左下叶颜色正常

        └─ 出血失控/下叶误伤 → 中转开胸

```

  

**底线**：无近端控制 + 无下叶支气管确认 → 不启动本流程。

## 五、关键要点总结

  

1. **绕开优于正面攻坚**——A1+2+3 后方钙化通道建不起来，立即放弃原位游离，通过支气管去张力来改善入路。

2. **支气管可控开放是"钥匙"**——部分或完全离断上叶支气管后，上叶失去固定、向头侧牵引幅度大增，A1+2+3 从"深部难暴露"变为"远端可处理"。

3. **安全网要先行**——近端肺动脉控制带 + 下叶支气管确认是启动应急流程的两个前置条件，缺一不可；出血失控或下叶误伤随时中转开胸。

## 六、通用提速原则

  

| 原则 | 要点 |

|------|------|

| 顺序即纪律 | 顺序固定、动作程序化，减少决策成本 |

| 叶裂最后处理 | 从纵隔侧依次完成肺门结构离断，最后沿已建立的安全平面完成叶裂 |

| 牵引标准化 | 每步规定助手牵引方向，不临时指挥 |

| 淋巴结嵌入主流程 | 5/6/10L/11L 随主步骤"过路清扫"，不做独立清扫时段 |

| 一次通过率 | 每个吻合器击发前隧道贯通+过带；击发次数↓=时间↓ |

| 录像计时复盘 | 分步计时，3–5 例后时间黑洞自现 |
