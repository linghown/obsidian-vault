## 表1．加速肺萎陷技术的建议、争议与注意事项

| 技术     | 建议                                 | 争议与注意事项                                     |
| ------ | ---------------------------------- | ------------------------------------------- |
| 封闭通道   | 在打开胸膜前已开始 OLV 时，应常规采用。             | 尚无相关并发症报道。                                  |
| 连接氧源   | 优点是在不干扰手术的情况下改善动脉血氧合。              | 缺乏临床研究证实能否改善肺萎陷质量。                          |
| 提前 OLV | 在胸膜打开前至少 6 分钟开始 OLV。               | 须联合封闭通道技术。                                  |
| 断开呼吸回路 | 胸膜腔打开时立即断开，持续至二氧化碳监测波形消失。          | 最佳断开时点和持续时间尚未明确；存在高碳酸血症风险。                  |
| 支气管吸引  | 胸膜腔打开时，以 −30 cmH₂O 吸引 1 分钟。        | 可能造成气道黏膜损伤及肺水肿；压力与时长存在争议；能否推广至单孔 VATS 尚不明确。 |
| 吸入 N₂O | 从肺隔离装置置入到开始 OLV 期间吸入 N₂O，FiO₂＝0.5。 | 术中高 N₂O 暴露增加围术期并发症；存在临床使用限制；破坏臭氧层并产生温室效应。   |
| 纯氧通气   | 从麻醉诱导到开始 OLV 期间使用纯氧通气。             | 围术期肺不张发生率增加。                                |
| 挥发性麻醉药 | 以 4%–6% 地氟烷维持全身麻醉。                 | 具有温室效应；需要大型前瞻性多中心试验。                        |
• 掌握OLV期间肺萎陷的生理机制，是实施加速肺萎陷技术的关键，尤其是“肺萎陷的两个阶段”及
“潮汐式气体运动”机制。
• 提前OLV应与封闭通道技术联合使用。
• 断开呼吸回路和支气管吸引加速第一阶段；吸入N2O或100%氧气加速第二阶段。
• 无论采用哪种加速技术，麻醉诱导前都应充分预充氧（去氮）。
• 使用BB或实施单孔VATS时，可能需要采用加速肺萎陷技术，才能获得满意的萎陷质量。

单肺通气（one-lung ventilation，OLV）
