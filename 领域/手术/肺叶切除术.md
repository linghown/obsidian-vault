## 一句话总结

肺叶切除术的关键，不是离断得快，而是术前把解剖看清、术中把暴露做足、按最安全的顺序建立通道，并尽量把漏气和出血风险前移处理。

## 总体原则

1. 先暴露，再离断。
2. 先建立入口和出口两个视角，再过器械。
3. 过血管尽量不要垂直，锐角或小于90度角，避免正顶血管。
4. 过支气管尽量紧贴支气管壁，不在模糊软组织内盲穿。
5. 淋巴结清扫不仅是根治要求，也是显露肺门结构的重要手段。
6. 叶裂发育差时，不宜强行开裂，优先考虑单向式或 fissure-last 思路。

## 核心技巧

### 1. 暴露

- 完整打开前后纵隔胸膜，尽量沿肺边缘推进。
- 先做出静脉、支气管、动脉之间的自然间隙，再考虑过枪。
- 重要结构两端都要游离，避免只有单侧视角就离断。

### 2. 过血管、过支气管

- 过血管常用 `45–75°` 入路，退出时尽量与血管平行。
- 过支气管时先贴气管壁走，再缓慢扩大间隙。
- 能“先分离一个安全薄层，再扩大”的，不直接硬穿。
- 单孔时器械冲突更明显，角度和牵拉方向比力量更重要。

### 3. ==叶裂处理==

- 先找稳定标志：后段动脉、中央静脉、三叶交界处、中间干支气管。
- 沿肺动脉表面鞘膜或支气管方向建隧道。
- ==叶裂发育差==、肺气肿、肺门致密时，==优先考虑 fissure-last==，减少漏气。

### 4. 淋巴结

- N11、N10、7组常常应在关键离断前清理，用于暴露支气管入口和动脉分支。
- 右侧 2/4 组、7 组，左侧 5、7 组，要提前规划清扫窗口。
- 清淋巴结时整体推移优于碎片化撕扯，避免出血遮挡视野。

## 各肺叶要点

### 右上肺

- 通常最容易入门，但变异和叶裂判断仍要谨慎。
- 常见思路：
  - 动脉 → 支气管 → 静脉
  - 或  静脉 → 动脉 → 支气管
- 关键点：
  - 先充分显露上中叶静脉间隙。
  - 回升支动脉是关键标志。
  - 打开后纵隔胸膜和水平裂时，要始终记住肺动脉主干位置。

### 右中叶

- 叶裂不发育时难度上升明显。
- 常见思路：静脉 → 支气管 → 动脉 → 叶裂。
- 关键点：
  - 先明确上、下肺静脉关系。
  - 支气管离断后常有助于动脉暴露。
  - 无叶裂时，不要在疑似血管区粗暴剥离。

### 右下肺

- 常见思路：
  - 静脉/下肺韧带 → 支气管 → 动脉
  - 或先开部分叶裂暴露动脉后再完成其余步骤
- 关键点：
  - 下肺韧带和后纵隔胸膜要做充分。
  - 中下叶间标志淋巴结常是进入支气管、动脉层面的窗口。
  - 支气管离断后，动脉常更易显露。

### 左上肺

- 血管分支更复杂，顺序可变，但前后胸膜和叶裂暴露必须扎实。
- 常见思路：胸膜/叶裂建立 → 静脉 → 舌段动脉或后升支 → 支气管 → 其余动脉。
- 关键点：
  - 主动脉弓附近操作需更稳，避免热损伤和牵拉过猛。
  - 静脉与支气管间隙是关键通道。
  - 叶裂内出血时先压迫，再恢复解剖，不要急于追点止血。

### 左下肺

- 常见思路：下肺韧带/后纵隔 → 叶裂建立 → 静脉 → 支气管 → 动脉。
- 关键点：
  - 下肺静脉和支气管之间的隧道常是核心通路。
  - 提起支气管断端有助于暴露动脉。
  - 左侧 7 组和 5 组清扫应提前融入整体步骤，而不是术末补做。

## 高风险点

### 1. 出血

- 多发生于叶裂内误入、动脉鞘膜层次不清、器械正顶血管。
- 处理原则：
  - 先压迫，先恢复视野，再决定缝、夹、补或转开胸。
  - 不在血泊里继续“猜解剖”。

### 2. 漏气

- 多见于裂发育差、肺气肿、粗暴开裂、能量器械离断肺实质过多。
- 优化点：
  - 优先 fissure-last
  - 尽量沿正确层面建隧道
  - 漏气边缘可连续缝合压迫修补，但避免过深伤及血管

### 3. 解剖误判

- 常见于回升支动脉、叶间静脉、变异静脉、动脉和支气管贴近区域。
- 解决方式：
  - 术前 CT 逐支确认
  - 术中两端游离
  - 淋巴结先清掉再判断结构

## 可行性优化

### 术前

- 术前 CT 必须回答 4 个问题：
  - 叶裂发育如何
  - 肺动脉和静脉有无明显变异
  - 肿瘤位置与肺门、叶裂关系如何
  - 是否存在钙化淋巴结、致密粘连、高难度肺门
- 复杂病例优先做 3D 重建或术前手术路线模拟。
- 对单孔方案，不只看病灶大小，更要看肺门复杂度和团队熟练度。

### 术中

- 优先选择最容易安全建立通道的结构开始。
- 视野不清时，退回暴露步骤，不在模糊层面推进。
- 叶裂差时，尽量减少无效开裂和肺实质损伤。
- 清淋巴结和解剖暴露同步进行，避免分成完全割裂的两段。

### 围术期

- 术前戒烟、呼吸训练、营养优化。
- 术中缩短无效胸腔操作时间，及时吸痰和充分复张。
- 术后早下床、胸管精细管理、警惕肺不张和肺炎。

## 我的手术清单

- 术前先判断：裂优先，还是单向法/裂最后。
- 先找本叶最稳定的解剖标志，不凭记忆硬做。
- 每次过枪前都确认：
  - 入口在哪里
  - 出口在哪里
  - 深面是什么
  - 一旦出血压哪里
- 任何关键结构离断前，都问自己一句：两端真的都看清了吗？

## 个人备注

- 右上肺最易入门，但不是最容易掉以轻心。
- 真正决定稳定性的，不是“会不会做”，而是“什么时候不该硬做”。
