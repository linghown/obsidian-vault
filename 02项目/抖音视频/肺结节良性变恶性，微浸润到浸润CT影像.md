### 一、第一阶段，良变恶

先纠正一个概念：大多数良性肺结节不会“变成”恶性。肉芽肿、错构瘤、机化性肺炎这类良性病变本身一般不转化。你问的这种“演化”，主要是指肺腺癌的一条连续谱系：

非典型腺瘤样增生（AAH）→ 原位腺癌（AIS）→ 微浸润腺癌（MIA）→ 浸润性腺癌（IAC）

从癌前病变到浸润，本身就是一个连续过程。所以临床判断从来不是看一张CT定性，而是 形态 + 密度 + 随访动态变化 三者一起看，最终确诊靠病理。


3个特征：<font color="#ff0000">变大、变实、变丑。</font>
变大：大于2mm，实际要3-5mm
变实：实性成分增加，
变丑：毛刺，分叶，胸膜凹陷/牵拉，血管征，空泡征，

### 二、重点：从微浸润腺癌（MIA）到浸润性腺癌（IAC），CT怎么变

- MIA：肿瘤≤3cm，以贴壁生长为主，任一浸润灶最大径≤5mm，且没有胸膜、血管、淋巴管浸润和肿瘤性坏死
- IAC：浸润成分>5mm，或出现腺泡/乳头/微乳头/实性等浸润性生长方式

CT上的实性成分大致对应病理的浸润部分，磨玻璃部分对应贴壁生长部分，所以从MIA往IAC走，变化集中在实性成分上：

| 对比项      | MIA为主时                               | 向IAC发展时                                                                |
| -------- | ------------------------------------ | ---------------------------------------------------------------------- |
| 实性成分大小   | 一般 <5mm                              | >5mm 是核心界限，有研究提示==薄层CT上实性成分>7.3mm==时更明确指向浸润性腺癌                         |
| 实性占比 CTR | 多 <0.25，MIA的实性成分最大径一般小于5mm、C/T比<0.25 | CTR越过0.25、向0.5甚至更高走；CTR越大，浸润概率越大，JCOG研究也以CTR≤0.25作为影像学非浸润的界值、>0.25为浸润性 |
| 结节类型     | 纯磨玻璃或以磨玻璃为主的部分实性                     | 部分实性中实性占优，甚至转为实性结节；贴壁为主型IAC表现为部分实性或实性、实性成分>5mm，非贴壁为主的IAC则直接是实性结节       |
| 总大小      | 多在1-2cm上下                            | 整体继续增大，磨玻璃范围可能也在扩，但实性部分长得更快                                            |
| 边缘形态     | 类圆形、边缘相对清楚，分叶毛刺轻微或没有                 | 分叶加深、出现短毛刺、形态不规则；不规则边缘、支气管充气征中断/扭曲和胸膜凹陷是区分浸润癌的重要征象                     |
| 内部结构     | 空泡、支气管充气多比较“干净”                      | 支气管扭曲截断、血管穿行增粗、胸膜牵拉加重，可出现不规则空洞                                         |
| 生长速度     | 很慢，几年才见明显变化                          | 实性成分在相对短的随访间隔里（如3-6个月至1年）就可见增长                                         |

### 三、必须知道的局限

- CT的实性成分≠病理浸润灶的精确大小，纤维化、肺泡塌陷、炎症也能造成“假实性”，所以5mm在影像上只是高度提示，不是宣判
- <font color="#ff0000">黏液型腺癌是例外，常直接表现为实性</font>，上面这套磨玻璃规律不完全适用
- 纯磨玻璃结节做PET-CT常常是阴性的，阴性不能排除早期腺癌
- 一次CT报告写“考虑MIA/IAC”只是影像预判，分型最终以手术切除后的完整病理为准
